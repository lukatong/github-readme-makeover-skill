# Inventory Watch

The best monitoring tool.

![Build](https://example.invalid/build.svg) ![Docker](https://example.invalid/docker.svg) ![Stars](https://example.invalid/stars.svg)

Inventory Watch checks websites and sends an alert when something changes. It has selectors, proxies, filters, notifications, a REST API, Docker, and more.

## Install

Install Docker. Clone this repository. Run the container. See the docs if it does not work.

```bash
docker run inventory-watch
```

## Features

- Fast
- Flexible
- Easy to use
- Telegram
- Email
- Webhooks
- CSS selectors
- XPath
- Browser mode
- API
